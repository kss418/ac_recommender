# Competitive Programming Editorial IR

This directory defines the intermediate representation used to normalize
competitive programming editorial content for retrieval and recommendation.

## Documents

- `editorial-ir-v1.md`: Core JSON schema
- `field-rules.md`: Field-level rules and empty value policy
- `templates.md`: Template-specific schemas
- `taxonomies.md`: Solution model and skill atom taxonomies
- `examples.md`: Complete examples
- `embedding.md`: Embedding document generation rules

Machine-readable validation schema: `../../schema/editorial-ir-v1.schema.json`
